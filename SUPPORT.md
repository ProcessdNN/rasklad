# Support

## Where to ask

- **Bug**: open an issue and pick the bug report template.
- **Question or idea**: use Discussions.
- **Security problem**: see [SECURITY.md](SECURITY.md). Do not open a public
  issue.

## What to include

The bug report template asks for everything that usually matters. Two fields
decide most cases:

- **Windows version.** Layout switching depends on it.
- **Where it fails.** "Everywhere", "only in some applications" and "only
  while the rasklad window is focused" are three different problems.

If you can reproduce the problem on demand, attach a debug log. The template
has the command.

## What to expect

Rasklad is a hobby project with one maintainer. Reports are read, but a fix can
take a while, and some reports end with "works as intended". There is no
support contract and no promised response time.
